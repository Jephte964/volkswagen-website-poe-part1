# Volkswagen South Africa Website Project (Part 1)

## Student Information
- Project: PoE Website Development – Part 1
- Organisation: Volkswagen South Africa (Educational Project – Volkswagen Crafter themed)
- Technologies Used: HTML5
- Type: Multi-page website development project

---

## Project Overview

This project is a multi-page website developed as part of a web development assignment.  
The website represents Volkswagen South Africa in an educational context, focusing on showcasing vehicles, company information, services, and customer interaction through enquiry and contact forms.

The main objective of this project is to demonstrate the ability to create a structured, functional, and well-organised website using HTML.

---

## Organisation Overview

Volkswagen South Africa is a well-known automotive company that produces reliable, innovative, and high-quality vehicles for both personal and commercial use.

This project is a fictional educational representation of the organisation, including vehicles such as the Volkswagen Golf, Polo, Tiguan, Amarok, Passat, and T-Cross, as well as a focus on commercial vehicles like the Volkswagen Crafter concept.

---

## Website Goals and Objectives

The main goals of this website are:

- To present Volkswagen vehicles in a structured and user-friendly way
- To provide clear information about products and services
- To allow users to browse different vehicle categories
- To enable users to submit enquiries through forms
- To demonstrate proper HTML structure and navigation between pages

---

## Key Features and Functionality

- Multi-page website (minimum 5 pages)
- Consistent navigation menu across all pages
- Homepage with featured vehicles
- About page with company information, mission, and vision
- Services page with vehicle categories and descriptions
- Enquiry page with a functional HTML form
- Contact page with contact details, locations, and message form
- Use of images to enhance user experience

---

## Website Structure (Sitemap)

- `index.html` → Home page (featured vehicles and introduction)
- `about.html` → Company overview, mission, vision, team
- `services.html` → Vehicle categories and services
- `enquiry.html` → Customer enquiry form
- `contact.html` → Contact details and message form
