# Volkswagen South Africa Website Project (PoE – Part 1, Part 2 & Part 3)

## Student Information
- Project: PoE Website Development
- Organisation: Volkswagen South Africa (Educational Project – Volkswagen Crafter themed)
- Technologies Used: HTML5, CSS3, JavaScript
- Type: Multi-page responsive website development project

---

## Project Overview

This project is a multi-page responsive website developed as part of a web development assignment.

The website represents Volkswagen South Africa in an educational context, showcasing vehicles, services, and customer interaction through enquiry and contact forms.

The project demonstrates the use of HTML, CSS, JavaScript, and SEO principles to build a structured and user-friendly website.

---

## Organisation Overview

Volkswagen South Africa is a well-known automotive company that produces reliable and innovative vehicles.

This project is a fictional educational representation including models such as Golf, Polo, Tiguan, Amarok, Passat, and T-Cross, as well as commercial vehicle concepts.

---

## Website Goals

- Present Volkswagen vehicles in a structured way
- Provide clear information about services
- Allow users to submit enquiries and contact messages
- Demonstrate responsive web design
- Apply JavaScript form validation
- Implement SEO best practices

---

## Features Implemented

### HTML
- Multi-page website (5 pages)
- Consistent navigation menu
- Forms for enquiry and contact
- Structured semantic layout

### CSS (Part 2)
- External stylesheet (`style.css`)
- CSS variables for consistent theme
- Responsive design using media queries
- Grid layout for vehicle cards
- Styled forms and navigation
- Mobile-friendly design

### JavaScript (Part 3)
- Form validation (enquiry form)
- Email validation
- Phone number validation
- Message length validation
- User feedback messages
- Prevent default form submission

### SEO Implementation
- robots.txt file created
- sitemap.xml created
- Proper page structure and headings
- Image alt attributes
- Clean URL structure

---

## Website Structure

- `index.html` → Home page
- `about.html` → About Volkswagen
- `services.html` → Vehicle services
- `enquiry.html` → Customer enquiry form
- `contact.html` → Contact form
